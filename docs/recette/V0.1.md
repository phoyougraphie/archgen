## Installation (H01)

La copie de développement a été déplacée dans `tmp/plugins-avant-ag020/` avant l'essai : le menu ne montrait alors plus ARCHGEN.

| Étape | Attendu | Observé | Résultat |

| Installer par le Gestionnaire d'extensions | Listée et active | ARCHGEN « Enabled », « Sans signature » | OK |
| Fichiers installés | Identiques au dépôt | `archgen/` identique, `archgen.rb` de même empreinte, plus de fichier Diagnostic | OK |
| Menu | Deux entrées, plus de Diagnostic | Nouveau bâtiment, Modifier le bâtiment sélectionné | OK |

| Réactiver (API) sans redémarrer | Menu revenu, une entrée | Sous-menu ARCHGEN présent une fois | OK |
| Redémarrer activée | Code chargé depuis Plugins | La recette ci-dessous a tourné sur ce démarrage ; `extension_path` dans Plugins | OK |
| **Basculer dans le Gestionnaire, redémarrer** | État conservé | **Non conservé : voir ci-dessous** | Réserve |

**Réserve sur le Gestionnaire.** Sur ce poste, le bouton Enabled/Disabled agit dans la session, mais `PrivatePreferences.json` garde l'ancienne valeur après une fermeture normale : deux essais vers Enabled, un vers Disabled. `check` et `uncheck` en Ruby, suivis d'une fermeture normale, écrivent bien l'état. ARCHGEN ne lit ni n'écrit ce réglage. La cause n'est pas établie, et je n'ai pas fait le même essai sur une autre extension pour ne pas toucher à vos réglages. Le guide donne le contournement.

## Limites

- **Profil non vierge :** Windows et le profil SketchUp sont ceux du poste, avec vos autres extensions, dont `su_mcp` et Solid Inspector. Seul ARCHGEN était retiré avant l'installation. Un conflit qui n'apparaîtrait que sans ou avec d'autres extensions n'est pas couvert.
- **Extension non signée :** une politique de chargement limitée aux extensions identifiées la bloquerait. Non testé.
- **H09 :** la mise à l'échelle à 150 % reste un zoom CSS, et la connexion n'a pas été coupée. Le panneau ne contient aucune ressource distante (test de contrat).
- **H10 :** clics DOM pour le rejeu ; l'expiration de la confirmation est simulée par l'horloge.
- **H03, H05 et H11 :** Annuler et Rétablir passent ici par l'API ; le vrai menu a été exercé sur une création.
- **Console :** seul le dernier affichage a été lu, et il ne montre que des avertissements de sonde. Une erreur dans un rappel de dialogue pendant le rejeu n'a pas été cherchée dans toute la console ; les sondes en auraient vu les effets.
- **H11 :** portable non isolé, mesures indicatives de ce poste. Modèle remis à zéro sans nouveau document ; redessin non mesuré.
- **Export :** OBJ et Blender seulement ; Shell LOD 0 seulement.
- **D-01 reste ouverte :** le champ « Variation des baies » est le plus souvent refusé dès qu'il n'est pas nul. Aucun profil livré ne l'utilise.
